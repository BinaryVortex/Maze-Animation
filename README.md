# Maze Animation

A small interactive maze animation built with plain HTML, CSS and JavaScript.

![Maze Animation demo](./Screenshot%202024-08-25%20154941.png)

Overview
--------
This repository contains a simple web page that generates and animates a maze. It demonstrates algorithmic maze generation and rendering using the Canvas/DOM (see index.html and script.js).

Features
--------
- Generates a maze procedurally
- Animates the generation and/or solution process
- No build tools or external dependencies — just open index.html in a browser

Getting started
---------------
To run the demo locally:

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Maze-Animation.git

2. Open the project folder and double-click `index.html`, or serve it with a simple static server:

   python -m http.server 8000
   # then open http://localhost:8000 in your browser

Usage
-----
- The main demo is in `index.html` and the animation logic is in `script.js`.
- `style.css` contains minimal styling.

Project structure
-----------------
- `index.html` — demo page
- `script.js` — maze generation and animation logic
- `style.css` — styles
- `Screenshot 2024-08-25 154941.png` — demo screenshot used in this README
